# だいなそー

グミちゃんを守るため、毎日修行している やさしい戦士「なそ」と過ごす、スマホ向けの癒しアプリです。
冒険者の拠点でごはん（なそ飯）を食べたり、家具を置いたり、いっしょにゲームをしたりできます。

- 公開URL: https://g-yama0920.github.io/dainaso/
- ホーム画面に追加すると、アプリのように使えます（オフラインでも開けます）。
- 練習モード: URL の最後に `?practice` をつけると、すべてのゲームを練習できます（ゴールドはもらえません）。

## メモ

- 「つんつ君」と同じしくみをもとにした別キャラ版です。セーブデータは別（`dinaso-v1` / `dinaso-snd` / `dinaso-album-v1`）。
- `index.html` を更新したら、`sw.js` の `VERSION` を上げると端末側も新しくなります。
- `src/` は組み立て用のファイルです（`python3 src/build.py && python3 src/patch.py`。元にする つんつ君 の index.html が必要）。
